# Choose a chart from the question

| Question | First choice | Alternate | Required data and caveat |
| --- | --- | --- | --- |
| Which articles received most impressions? | Sorted horizontal bars | Dot plot or ranked table | Latest lifetime impressions, dates and article age. Unequal ages limit fairness. |
| Is my follower count changing? | Line with observed markers | Table of dated changes | At least two profile snapshots. Do not invent daily points or attribute gains to an article. |
| Which posts convert exposure into interaction? | Scatter: impressions vs reactions + comments + reposts | Table including numerator, denominator and rate | All inputs from the same post/window; at least two complete posts. No causal claim. |
| Which articles have a different reaction mix? | Grouped bars | Absolute stacked bars | Comparable reaction/comment/repost counts. Percent stacks hide volume; pair with totals. |
| How do topics compare? | Bars with sample counts | Small multiples | Explicit topic mapping, comparable exposure age/window, complete metrics. Multi-tag articles can double-count; assign one primary topic or show overlap. |
| When does posting work best? | Day/hour heatmap | Per-slot dot plot | Actual posting timestamps/timezone, exposure-normalized windows, enough posts per slot. A few lifetime snapshots cannot answer this. |
| Does LinkedIn bring website readers? | Separate aligned time series or source breakdown | Source table | Plausible referral/UTM data and matching periods. Do not create a funnel from unmatched impressions and pageviews. |
| How did an article grow after publication? | Cohort curves by age | Small multiples | Repeated post snapshots plus publication time. Use observed intervals, no fabricated daily growth. |

Use a zero baseline for bar lengths. A line may use a narrower range if labelled and the range does not exaggerate changes. Keep units in axis labels, dates in the subtitle and missing data out of numeric calculations. Prefer directly labelled marks over a distant legend. Show exact values in a table, particularly where circles overlap. Retain the same data when switching chart style.

Every recommendation should name the underlying question and what evidence would change the conclusion. A chart with no useful decision behind it is optional, even if the data can draw it.
